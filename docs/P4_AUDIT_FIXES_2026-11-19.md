Дата: 19.11.2026. Проект: HA-felicity-battery. Ветка: fix/battery-bms-decoding.
Базовый коммит: 14d291cf8df3303de1d9a47e29a1391556378f98.
Стабильная main: a547418d924665945f0f924908f21407263f541e (не изменять).

## Аппаратные тревоги и достоверность данных

- Строгий validate_runtime больше никогда не обходится из-за ненулевого Bfault, Bwarn, BBfault или BBwarn.
- Только для явно выбранной FLA48200-P функция sanitize_runtime() создаёт отдельную копию пакета. Невозможные измерения заменяются на None, а корректные аппаратные тревоги сохраняются без подмены значением ноль.
- Частичный аварийный кадр допускается к существующим тревожным датчикам только после очистки повреждённых измерений. При отсутствии аппаратной тревоги невалидные обязательные измерения по-прежнему отклоняются с повторным чтением.
- Проверены SOH 0–100%, температура BTemp[0] −40…100°C, BMS Capacity Class до 1000 А·ч, runtime LVolCur, 16 ячеек 2000–4500 мВ. Допуск расхождения суммы напряжений ячеек с pack — 800 мВ.
- Некорректный ряд ячеек не должен отображаться как набор физических ячеек. Устойчивые обязательные измерения не теряются из-за невалидных необязательных SOH/температуры.
- Служебный raw ток Batt[1][0]=-1 остаётся измерением −0,1 А. На других моделях новые ограничения не применяются.
- Незаполненные показания становятся unknown, а не искусственным 0. Аппаратные лимиты BMS, инвертор и отопление не изменялись.

## Независимость основного опроса

- Успешно полученная realtime телеметрия имеет приоритет.
- Таймаут для каждого из необязательных basic/settings/Date — до 2 секунд, общий срок дополнительных чтений заканчивается за 3 секунды до исходного лимита полного цикла 25 секунд.
- Ранее существовавшие транспортные повторы (до 3 попыток на команду) не умножаются при ошибке TCP; дополнительное чтение выполняется только для полученного, но повреждённого кадра.
- Продолжительность штатного цикла при прямом чтении реальной FLA48200-P: 1,74 / 1,32 / 1,33 с.
- Статические basic-данные кэшируются на 300 секунд только для указанной модели; telemetry, settings и Date по-прежнему опрашиваются каждые 30 секунд.
