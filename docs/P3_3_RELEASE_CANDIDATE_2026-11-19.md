## Что входит

- Локальный TCP 53970, четыре ASCII-команды только чтения, обработка составного JSON, таймауты и ограничение размера.
- Структурная валидация FLA48200-P до публикации данных и сохранение реальных аппаратных тревог при плохом кадре.
- Восстановление штатным HA DataUpdateCoordinator; 25 секунд на цикл, 30 секунд период.
- Статический базовый ответ FLA48200-P с TTL 300 секунд; телеметрия, настройки и Wi-Fi продолжают читаться каждые 30 секунд.
- 16 напряжений ячеек, SOC/SOH, напряжение, ток, мощность, паспортные 205 А·ч отдельно от класса BMS 250 А·ч.
- Неизменённые исторические entity_id / unique_id, аппаратные коды и программа диагностики разброса.
- Теневой декодер P1 с 42 сравнениями; переключение рабочих датчиков **заблокировано**.
- Исправленное отображение BCU/BMU, исходные поля версий доступны в атрибутах.
- Описания протокола и модели: P3_2_LOCAL_TCP_PROTOCOL.md и P3_2_MODEL_EVIDENCE.md.

## Не закрытые доказательством условия

1. **P1.3 открыт.** На реальной FLA48200-P пока не подтверждены Bstate/Estate при сильном заряде, разряде или естественном переходе на резерв; новый декодер остаётся исключительно параллельным.
2. Назначение BattList, знаков токов под нагрузкой, поля BTemp[1] и битов ненулевых Fault/Warning не установлено первичными измерениями.
3. Другие модели не прошли проверки собственных профилей; для них оставлен исторический парсер. Type/SubType не является уникальным идентификатором изделия.
4. Реальный физический разрыв Wi-Fi не инициировали, восстановление проверялось локальным TCP-имитатором и по эпизоду естественного сбоя.
5. В репозитории пока нет GitHub Actions CI. Результат подтверждён локальными тестами и установленным HA, **не** независимой CI-системой.
6. При согласовании отдельной стабильной публикации потребуется изменение version 0.2.3, повторные тесты, решение о GitHub Release и переносе в main. Сейчас **не выполнять**.

## Безопасность

- Только чтение диагностических данных. Без записи в BMS, отключений сети, переключения инвертора или отопления.
- TCP API не имеет видимой в клиенте TLS/аутентификации; держать в доверенной локальной сети, наружу порт не пробрасывать.
- Примеры TCP обезличены: не публиковать номера устройств, IP, токены и MAC.
- Индикаторы Cell Voltage Drift High / Confirmed программные, а не аппаратные Fault/Warning. Не переименовывать и не отключать без отдельной задачи.
